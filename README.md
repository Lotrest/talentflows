# TalentFlows
 
**AI-агент для автоматизации поиска работы.** Платформа берёт на себя рутину: мониторит вакансии на HH.ru и LinkedIn, отправляет отклики и ведёт переписку с работодателями — в контексте твоих навыков и истории диалогов.
 
---
 
## Что делает платформа
 
- **Мониторинг вакансий** — агент ищет по ключевым словам и навыкам пользователя, проверяет что вакансия открыта
- **Автоматические отклики** — генерирует персонализированные сопроводительные письма и откликается
- **Контекстные ответы** — понимает историю переписки с каждым работодателем, отвечает как человек
- **Дашборд** — все отклики, статусы и диалоги в одном месте (веб + мобильное приложение)
- **Тарифы** — бесплатный и платный план

## Стек
 
**Frontend**
- Next.js (App Router)
- React Native (мобильное приложение)
- Tailwind CSS
**Backend**
- Node.js / FastAPI
- PostgreSQL
- BullMQ (очереди задач)
**AI & Автоматизация**
- Claude API — генерация писем и контекстных ответов
- Playwright — браузерная автоматизация платформ
- HH.ru API
**Инфраструктура**
- Supabase Auth
- Firebase (push-уведомления)
- Stripe / YooKassa (платежи)
